VolgaTerms

Автоматизация рабочих процессов с сервисами Google

VolgaTerms — внутренний сервис для автоматизации рабочих процессов и интеграции корпоративных инструментов с сервисами Google.

Назначение сервиса

Сервис выполняет автоматизированные сценарии, созданные в n8n, включая работу с Google Sheets, Google Drive, Gmail и Google Calendar.

Работа с Google API

Доступ к сервисам Google пользователь предоставляет добровольно через OAuth 2.0. Приложение получает только те разрешения, которые пользователь подтверждает при авторизации.

Полученные данные используются исключительно для выполнения настроенных автоматизаций.
